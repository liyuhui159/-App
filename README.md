# 灵犀智能自动记账 App

原生 Android 自动记账 App，支持通知监听、无障碍辅助识别、账单统计与 AI 智能判断。

## 新增 AI 功能

- **AI 智能导入**：粘贴微信、支付宝、银行卡、外卖或混合账单文字，AI 判断是否是真实交易，并提取金额、收支类型、分类、账户、日期和备注。
- **支付通知 AI 判断**：支付类通知优先交给 AI 判断；接口失败、未配置或未达到置信度时，自动回退原有本地关键词规则。
- **严格结果校验**：只接受规定的收支类型、分类和账户，过滤零金额、异常大额、低置信度与非账单内容。
- **可配置接口**：兼容 OpenAI Responses API，以及常见 OpenAI Chat Completions 兼容接口；可在 App 中填写完整接口地址和模型名称。
- **API Key 加密保存**：使用 Android Keystore + AES/GCM 加密后存储，不会直接写入源码或普通明文配置。
- **去重保护**：同一支付通知在短时间内不会重复请求 AI 或重复入账。

## 使用方法

1. 安装并打开 App，首先进入“灵犀 AI 记账”页面。
2. 在“API 设置”中填写：
   - 完整接口地址，例如 `https://api.openai.com/v1/responses`
   - 模型名称，例如 `gpt-5-mini`
   - API Key
3. 点击“保存 API 设置”，再点击“测试接口”。
4. 在 AI 智能导入框粘贴账单文字，点击“AI 智能判断”。
5. 检查识别结果，点击“确认并全部入账”。
6. 点击“打开完整账本与统计看板”进入原来的看板、流水、预算和设置页面。

## 自动记账权限

为了识别支付通知和支付页面，可在完整账本的“设置”中开启：

- 通知权限
- 通知使用权
- 无障碍服务

AI 通知判断可以在 AI 设置页单独关闭；关闭后仍使用本地规则。

## 支持的账目字段

- 收支：收入、支出
- 分类：餐饮、交通、购物、住房、学习、医疗、娱乐、通讯、人情、工资、退款、其他
- 账户：微信、支付宝、银行卡、信用卡、现金、其他

## 隐私与密钥安全

账本数据保存在本机 SQLite 数据库中。只有用户主动粘贴的账单文字，或满足支付通知过滤条件的通知文字，才会发送至配置的 AI 接口。

Android Keystore 可以保护 API Key 的本地静态存储，但无法彻底阻止客户端运行时密钥被提取。个人自用可以直接填写密钥；如果准备公开发布 App，应使用自己的后端代理保存大模型供应商密钥，并给客户端发放可撤销的短期令牌。

- compileSdk 35
- minSdk 23
- Java 17

使用 Android Studio 打开项目并执行 Build APK 即可。
