# 灵犀智能自动记账 App

原生 Android 自动记账 App。通过微信、支付宝和银行卡付款通知提取金额、账户和时间，并根据商家名称自动判断消费品类。

## 1.2.0 页面规划

主界面重新整理为四个区域：

- **首页**：本月支出、收入、结余、自动记账状态、快捷记账和最近账单。
- **流水**：按全部、支出、收入筛选，查看账单详情并导出 CSV。
- **统计**：显示本月分类占比；原有日、周、月图表与预算保留在高级统计页面。
- **我的**：集中管理自动记账权限、AI 分类、商家记忆、数据导出和高级功能。

API 地址、模型和 API Key 不再占用首页，只放在“我的 → AI 商家分类”中。

## AI 的实际用途

AI 不负责整段账单录入，也不会重新判断金额。自动记账按以下顺序工作：

1. 手机本地从付款通知中提取金额、收支类型、支付账户和时间。
2. 从通知标题和正文中提取商家或店铺名称。
3. 优先查询本机保存的“商家分类记忆”。
4. 对明确商家使用本地规则，例如：
   - 百果园、鲜丰水果、水果店 → 水果
   - 饭店、外卖、奶茶店 → 餐饮
   - 菜市场、肉铺、海鲜店 → 生鲜
   - 便利店、普通超市 → 日用品
   - 淘宝、服饰店、数码店 → 购物
5. 只有无法确定的商家才调用 AI 分类。
6. AI 分类成功后保存“商家 → 品类”，下次同一商家直接本地分类。

支持品类：餐饮、水果、生鲜、日用品、购物、交通、住房、医疗、学习、娱乐、通讯、人情、工资、退款、其他。

## AI 接口

支持 OpenAI Responses API，以及常见 OpenAI Chat Completions 兼容接口。设置项包括：

- 完整接口地址，例如 `https://api.openai.com/v1/responses`
- 模型名称，例如 `gpt-5-mini`
- API Key
- 最低分类置信度

返回结果使用 JSON Schema 约束；缺少置信度、品类不合法或置信度不足时，不会强行采用 AI 结果。

API Key 使用 Android Keystore 和 AES/GCM 加密保存。个人自用可以直接配置；公开发布时建议通过自己的后端代理调用模型接口。

## 自动记账权限

安装后进入首页，点击“自动记账”，在系统中开启“灵犀记账”的通知使用权。由旧版本升级后，因为通知监听组件发生变化，需要重新确认一次该权限。

## 构建环境

- Android Gradle Plugin 8.7.3
- compileSdk 35
- minSdk 23
- Java 17
- 当前版本：1.2.0（versionCode 3）

使用 Android Studio 打开项目并执行 Build APK，或使用仓库中的 GitHub Actions 自动构建 Debug APK。
